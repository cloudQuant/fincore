# fincore 0.5.0

Released 2026-09-01.

fincore 0.5.0 is the first published unified-core release. It preserves the
analytical capability areas formerly associated with Empyrical, Pyfolio, and
Alphalens while replacing their package-shaped access patterns with direct,
domain-owned modules.

## Breaking API boundary

This release intentionally removes `fincore.empyrical`, `fincore.pyfolio`,
`fincore.alphalens`, root-level metric callables, compatibility extras, and
tear-sheet façades. No compatibility shim is included. Migrate each integration
to the canonical module that owns its financial semantics.

| Capability | Canonical starting point |
| --- | --- |
| Metrics and drawdown analysis | `fincore.metrics` |
| Cash-flow-aware performance | `fincore.performance` |
| Portfolio inputs and reports | `fincore.portfolio`, `fincore.report` |
| Factor workflows | `fincore.factor_analysis` |
| Attribution and risk workflows | `fincore.attribution`, `fincore.risk` |

Read the [migration guide](../../getting-started/migration.md) before upgrading
an existing integration.

## Install

```bash
pip install "fincore==0.5.0"
```

Python 3.11 or newer is required. Install only the capability extras required
by your workflow, such as `fincore[visualization]`,
`fincore[factor-analysis]`, `fincore[report-pdf]`, or
`fincore[report-xlsx]`.

## Architecture and performance

The release has one canonical implementation path per public operation,
immutable boundaries around report and extension data, and renderer projections
that reuse a computed report document rather than recomputing financial values.
The published package should be validated against an application's own market
data, calendars, cash flows, and reporting requirements before production use.
