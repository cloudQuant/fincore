# fincore 0.5.1

Released 2026-09-20.

fincore 0.5.1 is a quality-maintenance release. It preserves the canonical,
breaking 0.5 public API introduced in 0.5.0: no legacy Empyrical, Pyfolio, or
Alphalens façades, flat root metric functions, compatibility aliases, or
stateful compatibility registries are restored.

## Quality and release verification

- The MyPy pre-commit hook checks the current package tree instead of removed
  pre-0.5 directories.
- Packaging contract tests isolate pytest's temporary staging output, so a
  local test run cannot accidentally alter the source copy used to construct a
  wheel or sdist.
- The static API scanner now validates the explicitly exported root version
  value without importing optional dependencies. Release validation compares
  that source root contract with the built wheel.

These are verification and developer-experience changes only. Financial
calculations, errors, dependencies, and the public namespace are unchanged.

## Install

```bash
pip install "fincore==0.5.1"
```

Python 3.11 or newer is required. Install only the capability extras needed by
your workflow, for example `fincore[visualization]`, `fincore[factor-analysis]`,
`fincore[report-pdf]`, or `fincore[report-xlsx]`.

If upgrading from a pre-0.5 integration, read the
[0.5 migration guide](../../getting-started/migration.md) first.
