# Changelog

The authoritative changelog is maintained in
[`CHANGELOG.md`](https://github.com/cloudQuant/fincore/blob/master/CHANGELOG.md).

The current release is **0.5.1**, a quality-maintenance update that preserves
the 0.5 unified-core API. It makes local, packaging, and source-to-wheel
contract checks reproducible without changing the public namespace. See the
[0.5.1 release notes](releases/0.5.1.md) for the verification changes and the
[0.5.0 release notes](releases/0.5.0.md) for the breaking upgrade boundary.
