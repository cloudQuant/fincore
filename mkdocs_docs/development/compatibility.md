# Historical compatibility record

This page is retained only as provenance for the pre-0.5 upstream comparison
work. It is **not** a statement of the current package API and it must not be
used as an integration guide.

fincore 0.5 preserves capability areas through canonical domains, not through
upstream-shaped compatibility modules. See the current
[migration guide](../getting-started/migration.md) and
[API reference](../api/index.md) for supported paths.
