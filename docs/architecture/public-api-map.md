## Invariants

1. Every public export belongs to exactly one surface and therefore exactly one
   profile.
2. The same logical operation (e.g. `sharpe_ratio`) may be bound onto multiple
   surfaces, but each binding has exactly one profile and result projection.
3. Strict façades never route through enhanced validation or stateful classes.
