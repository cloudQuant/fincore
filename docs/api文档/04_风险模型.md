# 风险模型 API

`fincore.risk` 提供超越标准 VaR/波动率的高级风险建模工具。

## 模块导入

```python
from fincore.risk.evt import evt_cvar, evt_var, extreme_risk, gev_fit, gpd_fit, hill_estimator
from fincore.risk.garch import EGARCH, GARCH, GJRGARCH, conditional_var, forecast_volatility
```

## 极值理论 (EVT)

### `hill_estimator(returns, threshold=None, tail="upper")`

Hill 尾部指数估计器。

- **returns**: `pd.Series` — 收益率序列
- **threshold**: `float`, 可选 — 正且有限的尾部幅度阈值；未提供时使用所选尾部幅度的 90% 分位数
- **tail**: `"upper" | "lower"` — 右侧收益尾部或反射后的左侧损失尾部
- **返回**: `tuple[float, np.ndarray]` — Hill 尾部指数与高于阈值的正幅度观测

对正尾部幅度 `x > u`，估计量为 `mean(log(x / u))`；它不对超额值
`x - u` 取对数。下尾在估计前会反射为正的损失幅度。

### `gev_fit(returns)`

拟合广义极值分布 (GEV)。

- **返回**: `dict` — 包含标准 GEV `xi`、`mu`、`sigma` 与 `n_blocks`；注意 SciPy
  内部 `genextreme.c` 的符号与标准 `xi` 相反

### `gpd_fit(returns, threshold=None)`

拟合广义帕累托分布 (GPD) 到尾部损失。

- **返回**: `dict` — 包含 `xi`、正的 `beta`、`threshold` 与 `n_exceed`
- **method="pwm"**: 使用 GPD 的 sample L-moment/PWM 估计；不能得到正尺度时会
  fail-closed

### `evt_var(returns, alpha=0.05)`

基于 EVT 的 Value at Risk。

- **alpha**: `float` — 有限且位于 `(0, 1)` 的尾部概率（默认 5%）
- **GPD 阈值约束**: 显式阈值必须满足 `alpha <= n_exceed / n_total`；未提供阈值时，
  查询会在可用时保留尾部 90% 分位数，否则自动降低阈值以覆盖目标概率
- **GEV 口径**: `alpha` 是 block-extreme 的尾部概率
- **返回**: `float` — VaR 值

### `evt_cvar(returns, alpha=0.05)`

基于 EVT 的 Conditional VaR (Expected Shortfall)。

- **返回**: `float` — 超过 VaR 的条件尾部均值；GPD 遵从同一阈值约束，GEV 在
  `xi >= 1` 时均值无穷并抛出异常

### `extreme_risk(returns)`

综合极端风险报告。

- **返回**: `pd.DataFrame` — 包含 GPD/GEV 参数、EVT-VaR、EVT-CVaR 和
  阈值/超阈值计数等

## GARCH 模型

### `GARCH(returns, p=1, q=1)`

标准 GARCH(p,q) 条件波动率模型。

**属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `params` | dict | 模型参数 (omega, alpha, beta) |
| `conditional_volatility` | pd.Series | 条件波动率序列 |
| `residuals` | pd.Series | 标准化残差 |

### `EGARCH(returns, p=1, q=1)`

指数 GARCH，捕获杠杆效应（负收益导致更高波动）。

### `GJRGARCH(returns, p=1, q=1)`

GJR-GARCH (Glosten-Jagannathan-Runkle)，另一种非对称 GARCH。

### `forecast_volatility(returns, horizon=1)`

基于 GARCH 的波动率预测。

- **horizon**: `int` — 预测步数
- **返回**: `float` 或 `np.ndarray`

### `conditional_var(returns, alpha=0.05)`

基于 GARCH 条件波动率的 VaR。

- **返回**: `float`

## 使用示例

```python
from fincore.risk.evt import evt_cvar, evt_var
from fincore.risk.garch import GARCH

# GARCH 波动率建模
garch = GARCH(returns)
print(garch.conditional_volatility.tail())

# EVT 尾部风险
print(f"EVT VaR(99%): {evt_var(returns, alpha=0.01):.4f}")
print(f"EVT CVaR(99%): {evt_cvar(returns, alpha=0.01):.4f}")
```
