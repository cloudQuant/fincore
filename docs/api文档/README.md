# Historical API Documentation Archive

The pages in this directory document the retired 0.4 package-shaped API. They
are retained only as provenance for the 0.5 capability migration and are not
maintained executable documentation. Their imports, façade classes, root
aliases, and extra names must not be used in Fincore 0.5.

Use the current [API Guide](../api.md), [Public API Map](../architecture/public-api-map.md),
and [Migration Guide](../MIGRATION.md) instead.
