# Support

- **Documentation:** <https://cloudquant.github.io/fincore/>
- **Usage questions:** [GitHub Discussions](https://github.com/cloudQuant/fincore/discussions) — ask here before opening an issue
- **Bug reports / feature requests:** use the issue forms at <https://github.com/cloudQuant/fincore/issues/new/choose>
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md); PRs target the `dev` branch ([branch model](docs/governance/branch-governance.md))
- **Security:** private reporting only — see [SECURITY.md](SECURITY.md)

Please include, when reporting a bug: the fincore version, a minimal
reproducer, and the full traceback.  Numerical-correctness reports are treated
as high priority.
