# Support

- **Documentation:** <https://cloudquant.github.io/fincore/>
- **Issues:** <https://github.com/cloudQuant/fincore/issues>
- **Discussions:** use GitHub Discussions for usage questions before opening an issue.
- **Security:** see `SECURITY.md` for private reporting.

Please include, when reporting a bug: the fincore version, a minimal
reproducer, and the full traceback.  Numerical-correctness reports are treated
as high priority.
